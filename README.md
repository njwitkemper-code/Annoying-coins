# Annoying-coins

The game is a 2D grid-based collection game where the player controls a character and moves around a 5x5 grid to collect coins. Players have 30 seconds to collect as many coins as possible while new coins appear on the grid. Random sound effects play throughout the game, and when time runs out, the player's score is compared against the leaderboard to determine whether they earned a spot in the top three.

## Firebase Database

This game uses Firebase Cloud Firestore to store player scores and maintain a leaderboard.
